# GAYMINX — Gaming Command Center

A full-stack gaming dashboard for tracking gaming sessions and discovering free-to-play games.

## Features

- **Dashboard**: Log sessions, view stats, edit/delete logs
- **Discover**: Browse 400+ free games from FreeToGame API
- **Auto-fetch metadata**: Game thumbnails and genres saved automatically
- **Find Similar**: Genre-based game discovery

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: PostgreSQL
- **API**: FreeToGame API
